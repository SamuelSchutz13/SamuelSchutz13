## 😄 About me

- 🛠️ I build local-first tools with **TypeScript end to end**: NestJS on the server, Vue and React in the browser.
- 🧪 I test what I ship: **Jest** and **Vitest** for unit and integration tests, **Playwright** for end-to-end tests in real browsers.
- 🔒 Privacy by default: my apps run on your machine, keep data in memory only, or encrypt it end to end.
- 🖥️ Ultrawide monitor fan, which is why I fixed YouTube and PES 2021 for 21:9.
- 🤝 I support open-source projects that help developers and the tech community.
